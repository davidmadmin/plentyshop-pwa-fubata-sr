# SCREWREBEL theme module instructions

Read the repository root `CLAUDE.md` and this module's `README.md` before changing this directory.

- Preserve all historical site-setting keys.
- Keep theme presentation scoped below `body.screwrebel-theme #app-container`.
- Do not theme purchase, account or authentication routes without explicit visual and interaction QA for those surfaces.
- Prefer module-owned CSS, plugins, settings and assets over edits to upstream application components.
- Update `README.md` whenever settings, route coverage or owned storefront surfaces change.
- Verify theme-off and theme-on states, desktop and mobile, before considering visual work complete.
